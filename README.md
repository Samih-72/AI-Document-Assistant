# AI-Document-Assistant
Built an intelligent document question-answering system that allows users to upload PDF documents and ask natural language questions. The application retrieves the most relevant document sections using vector search and generates context-aware answers with an LLM.

🛠️ Tech Stack
Python
LangChain
Mistral AI API
ChromaDB
Hugging Face Embeddings
PyPDF
Streamlit
python-dotenv
🔥 Features
Upload PDF documents
Extract text from PDFs
Split text into semantic chunks
Generate embeddings
Store embeddings in ChromaDB
Retrieve relevant document chunks
Generate answers using Mistral AI
Simple Streamlit web interface
